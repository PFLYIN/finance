# Finance

Projeto simples de controle financeiro pessoal com dashboard, cadastro de despesas e visualização por mês.

## Estrutura

- index.html — página principal
- assets/ — ícones e recursos visuais
- css/ — estilos organizados por responsabilidade
- js/ — lógica da aplicação

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Adicione entradas e saídas.
3. Os dados ficam salvos no navegador via `localStorage`.

## Observações

- O projeto foi organizado para facilitar manutenção e evolução.
- O arquivo principal de scripts pode ser ajustado dentro de `js/app.js`.
